## Checked Without a New Profile

- **Deluge:** [2.2.0 is the latest stable tag](https://github.com/deluge-torrent/deluge/releases/tag/deluge-2.2.0), and its [`DE` fingerprint generation](https://github.com/deluge-torrent/deluge/blob/deluge-2.2.0/deluge/core/core.py) is already represented by the existing `-DE220s-` profile.
- **BitComet:** the official [download archive](https://www.bitcomet.com/en/archive) lists 2.21 dated 2026-06-23, but BitComet does not publish source or tracker-signature documentation for that release. No 2.21 profile was added because its exact peer ID and request headers could not be verified.
- **uTorrent and BitTorrent Classic:** their official Windows download pages do not expose a stable version/build number or the tracker identity format. Existing profiles were retained; no newer profile was inferred from third-party client-identification tables.

## Verification Rule

Release recency alone is insufficient. The implementation requires an official source for the version, peer ID construction, and User-Agent. Dynamic fields are represented by the same character class and byte count used by the client source.
